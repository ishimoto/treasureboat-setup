Prepare

TBMonitor needs write access to:

  • Webserver cert file folder
  • Webserver doc root
    • You can create "<docroot>/.well-known/acme-challenge" and add write access only to this folder
    • If you have more than one domain with different docroots, you can add an alias, e.q.:
      Alias "/.well-known/acme-challenge" "/var/www/domain01/.well-known/acme-challenge"

Required modules

  • mod_log_config
  • mod_setenvif
  • mod_ssl
  • socache_shmcb_module
