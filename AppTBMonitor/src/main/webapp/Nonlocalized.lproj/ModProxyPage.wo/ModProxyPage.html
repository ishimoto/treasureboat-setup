<IfModule proxy_module>

ProxyVia Full

# Just in case: Deny proxy access

    Order deny,allow
    Deny from none
    Allow from localhost
</Proxy>

<Location /balancer-manager>
    SetHandler balancer-manager

    Order deny,allow
    Deny from none

</Location>

Step 3 (Optional): Changes in your Application class

TBWApplication will set the needed cookie for the stickysession used by mod_proxy balancer.
Setting org.treasureboat.webcore.appserver.TBWApplication.useModProxy=false in the properties file will stop generating the cookie.

If you need the client ip you need to ask for 'x-forwarded-for'. This can be done by using the static method String clientIP(TBRequest request) from TBWApplication.

Error handling

Example to add your own error pages

    # error folder
    <Location "/errors">
        Options -Indexes
        Order Deny,Allow
        Allow from all
    </Location>
    
    # Proxy everything except for /error
    ProxyPass /errors !

    # Service unavailable
    ErrorDocument 503 /errors/error503.html
